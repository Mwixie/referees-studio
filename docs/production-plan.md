# The Referees: animated-first production

Status: private development. No release authorised.

## Delivery order
1. Scene planner: narration, illustration brief, evidence references, approval status and image preview.
2. Illustration proof: three scenes in a consistent style, reviewed before adopting a model.
3. Motion proof: approved images with gentle movement, narration, captions and readable citations.
4. Animated edition; retain replaceable visual tracks for a later archival edition.

## Technical boundary
GitHub stores code and change history. No image model, paid API, cloud renderer or public website is connected. The first planner does not generate images or video. Never put credentials in browser code or repository files. A private repository does not automatically make a deployed website private.

## Proposed evaluation
Evaluate MoneyPrinterTurbo for assembly and ComfyUI for illustration generation; neither is adopted or installed yet. Review pinned versions, code and model licences, dependencies, hosting requirements and actual output quality before integration. Use original scripts and approved inputs, with no automatic publication.

## Three-scene technical test
Use generic civic explanations, not unverified claims about current events: a fair match, independent institutions, and citizens asking questions. Keep illustrative scenes visibly distinct from evidence. Test image consistency, pronunciation, caption legibility and iPad export. This is a technical test, not approved film narration.

## Shared work
Use scene IDs to coordinate Notion review notes and GitHub changes. No automatic Notion or Muse synchronisation is configured. Keep narration, citations, prompts, images and later archival replacements separate. Never include the producer's legal name in public-facing credits.
